# Hacıbayram Et Lokantası

Lokantanın tanıtım ve QR menü sitesi. Tek sayfa, ek kurulum gerektirmez.

- `index.html` — site (menü, fiyatlar, QR kod)
- `img/` — sitede kullanılan ürün görselleri ve dahil simgeleri
- `orijinal/` — yüksek çözünürlüklü ürün fotoğrafları
- `arsiv/` + `fotograflar.html` — gönderilen tüm fotoğrafların arşivi

## Yayınlama (GitHub Pages)
Settings → Pages → Branch: `main` / root → Save.
Site adresi: `https://yukselturkahmet.github.io/hacibayram-site/`
QR kod alanına bu adresi yazın (sonuna `#menu` ekleyin).
